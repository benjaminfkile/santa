# Design documents

- `site.md`: the technical design of this repository. Belongs here; edit it here.
- `DESIGN.md` and `contracts.md`: byte-identical copies of the originals in `wmsfo-api/docs`. Never edit them here; change the original and recopy.
- `wireframes/`: the site wireframes as design-canvas artboards (`*.dc.html` plus `canvas.json`). The seeded canvas page is regenerated from them and is not tracked.

Section references such as "contracts 1.3a" point into `contracts.md`.
