Tokens

One token file, both modes, contrast checked

Same rule as the portfolio: every color lives in one file, components never write a hex, and a unit test parses the file and fails the build if any pair drops under 4.5:1 for text or 3:1 for status colors. The chips below are computed live from the values on this page.

Typography

Plex for the body, one display face for the big lines

IBM Plex Sans and Plex Mono carry over from the portfolio unchanged: Sans for prose and UI, Mono for anything that came from the API at runtime (countdown, funds, speed, times). The display face is the one seasonal typographic decision, used only on H1 and H2. Pick it here or in the bar; the preview follows.

Icons

One drawing rule for every glyph

24px grid, 1.75px stroke, round caps and joins, no fills. The seasonal set (sleigh, gift, tree, snowflake, cookies) is drawn with the same rule as the utility set (menu, pin, compass, bell), so nothing looks pasted in. Rendered inline so they take the accent from the theme. The current library is served through img tags, which is why every icon paints black today.

Rules

What the rebuild commits to

These replace the accent, surface, and font-pairing site settings. The visitor gets one control: light, dark, or follow the system. The direction is chosen once, by you, and lives in the token file.

Theme

Light, dark, system

  • Default is system. No stored choice means the OS decides, live, via a matchMedia listener.
  • One toggle in the header flips between light and dark and stores the choice. A third option in the menu returns to system.
  • No flash. An inline script in the head stamps data-theme before any CSS loads, same as the portfolio.
  • Dark is native, light is a lit room. Light is not an inversion: same accent hue, darkened to pass on white.
Color

One accent, roles for the rest

  • The direction picks one accent. Red, green, and gold never all fight on one screen.
  • Gold is for the funds ring and the star. Green and holly red are status and live-pin roles, not decoration.
  • Neutrals carry a hue bias toward the direction (blue-black, pine-black, midnight), never flat grey.
  • Contrast is a test, not an opinion. Failing pairs fail the build.
Surfaces

Portfolio's hand, outdoors

  • 1px lines, 6px and 10px radii. No shadows in dark; one soft shadow in light.
  • Hover is 120ms, border to accent, nothing moves more than 2px.
  • Frost glass on the liftoff card and the live overlays only. Everywhere else stays flat.
  • 44px minimum on every tap target. Focus is a 2px accent outline.
Season

Christmas by restraint

  • Snow is a layer, on by default, off per visitor and per site setting. Small, slow, translucent.
  • Lights are optional and only on the header wire. If they read as kitsch in the real build, they go.
  • The brand mark is Montana with a gold star at Missoula, from the legacy logo. The map pin keeps its Santa hat.
  • Motion has one orchestrated moment: the hero rises on load. Everything else is micro.
Removed

Gone from the public site

  • The ten theme chips. Accent, surface, and font-pairing settings are deleted, along with the per-visitor overrides.
  • Patrick Hand and the Comic Sans fallback stack.
  • The wireframe look: 2px black borders, 18px cursive body, flat off-white everything.
  • Icons through img tags. The library moves to inline SVG components.
  • Route as points on a map. The route page is a high-resolution poster in a pan-and-zoom viewer. The live map draws the path actually flown.
  • Sponsor tiers. Sponsors sort by gift, largest first; tracker time is gift times a per-dollar rate; an admin can pin any sponsor to any position and override its time.
  • Any UI library. The public site stays hand-rolled: CSS modules, tokens, nothing else.
Enforcement

How it stays this way

  • tokens.css is the only file with a hex. A hex in a component module is a review failure.
  • Contrast test parses tokens.css on every CI run.
  • Coverage test asserts every className in src has a rule. Thirty-one classes ship unstyled today.
  • Playwright screenshots of every page and home state in both modes on every PR.
